## About This Resource

This site collects structured notes from an **8-week, project-oriented path into Agentic AI** — moving from core AI/ML concepts through NLP and prompt engineering, into agent design patterns, and finally into building real, no-code agentic workflows with **n8n**.

Every lesson follows the same simple template — **Notes**, **Key Points**, **Examples**, and **Questions** — so each page can be read on its own or worked through in order.

Not sure where to begin? Head to **[Start Here](/start%20here)** for the full week-by-week roadmap and checklist.
