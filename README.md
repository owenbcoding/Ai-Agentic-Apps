# Agentic AI Applications Notes

This repository contains structured notes for an 8-week learning journey focused on **Agentic AI applications**.

It is organized as a practical study companion that moves from AI/ML foundations to building and operating production-ready agent workflows.

## What This Repo Covers

- Core AI and ML fundamentals (AI vs ML vs Generative AI, classification, regression)
- Deep learning basics (neural networks, CNNs, backpropagation)
- NLP and transformer foundations
- Prompt engineering and RAG concepts
- Agentic AI design patterns (tools, memory, ReAct, planning vs execution)
- No-code agent automation with n8n
- Real workflow integrations (Google Sheets, Slack, Email, webhooks, APIs)
- Production concerns (security, monitoring, deployment choices)
- Career prep (resume and interview preparation)

## Repository Structure

The repository is split by week:

- `Week 1` to `Week 4`: Foundations (AI/ML, deep learning, NLP, LLM basics)
- `Week 5` to `Week 7`: Agent systems and workflow automation
- `Week 8`: Production readiness and interview preparation

Each markdown file represents one lesson/topic for that week.

## Practical Reset Plan (Week 1 First)

If the bootcamp feels too theory-heavy, use this build-first track.

### Week 1 Outcomes

By the end of Week 1, you should have:

- 1 runnable mini-project
- 1 metrics report
- 1 short demo (screen recording or live run)
- 1 reflection note (what failed and what you fixed)

### Day-by-Day Plan (Week 1)

#### Day 1: AI vs ML vs GenAI (90 minutes)

- Create a one-page decision guide:
  - Problem type -> AI / ML / GenAI / Agentic AI
- Map 10 real examples and explain each in 1-2 lines.

#### Day 2: Predictive AI vs Agentic AI

- Build a comparison sheet:
  - Input, output, tools, and when to use each
- Solve 5 business scenarios with your recommended approach.

#### Day 3: Classification Mini-Project

- Use a simple dataset (e.g., spam/churn/fraud style).
- Train a baseline classifier.
- Report:
  - Accuracy
  - Precision
  - Recall
  - F1-score

#### Day 4: Regression Mini-Project

- Use a numeric prediction dataset (sales/price/time).
- Train a baseline regressor.
- Report:
  - MAE
  - RMSE
  - R-squared

#### Day 5: Action Layer

- Convert model outputs into actions using rules:
  - Example: if churn risk > threshold -> trigger retention message
- Build a simple script that outputs recommended actions.

#### Day 6: Mini Agent Wrapper

- Add an LLM layer to explain predictions and actions in plain English.
- Build a simple CLI: "analyze this customer/region".

#### Day 7: Portfolio Packaging

- Write a clean README for the project:
  - Problem
  - Data
  - Method
  - Metrics
  - Demo
  - Limitations
  - Next steps

### Day 1 Exact Checklist (90-Min Version)

- 0-10 min: Choose 10 examples from real life/work.
- 10-35 min: Label each as AI, ML, GenAI, or Agentic AI.
- 35-55 min: Write 1-2 lines explaining each label.
- 55-75 min: Review and correct 2-3 weak classifications.
- 75-90 min: Publish notes and write 3 things learned.

### Rule for Progress

Use a 70/30 split:

- 70% building
- 30% watching/reading

Measure progress by what you can demo, not what you heard.
